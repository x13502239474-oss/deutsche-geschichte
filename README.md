# 德意志史诗 · DEUTSCHE GESCHICHTE

一个移动端优先的德国历史沉浸式阅读数字图书馆。

## 内容规模

- 26 个历史模块，59 章，563 个小节
- 正文约 214 万字，整理自《德国通史》（全六卷，邢来顺、吴友法主编）
- 11 个深度专题，平均约 3300 字/篇
- 39 位历史人物档案，支持关联跳转
- 交互时间轴、王朝世系、帝国政体结构图与多张历史地图

## 阅读功能

- 完整目录与连续长篇正文
- 字号调节、夜间阅读模式
- 本地书签、笔记与阅读进度（浏览器 localStorage）
- 全文搜索
- 专题分析与人物档案互相关联

## 资料说明

网站主体正文整理自《德国通史》六卷本，按主题重新编排，各章标注卷次来源。
李工真《德意志道路：现代化进程研究》与 Mary Fulbrook《德国史 1918—2014》
所提供版本为扫描图片版，无法提取文字，仅作为专题分析的问题意识参考；
网站未伪造原书引文或页码。

## 本地运行

```bash
python3 -m http.server 8000
```

浏览器打开 <http://localhost:8000/>。
